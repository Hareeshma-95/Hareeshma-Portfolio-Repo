# Hareeshma H — Portfolio

A responsive portfolio built with **HTML5 and CSS3 only**. It includes a dedicated resume link, profile photo, experience, skills, project and contact sections.

## Before publishing: add your resume PDF
1. Export your latest resume as a PDF.
2. Name the file exactly `resume.pdf`.
3. Place `resume.pdf` in the same root folder as `index.html`.
4. The **View resume** link in the hero section will then open the PDF.

The portfolio ZIP does not contain a resume because no resume document was provided.

## Preview locally
Open `index.html` in a browser. Keep the `assets` folder beside it.

## Deploy free using GitHub Pages
1. Create a GitHub repository, for example `hareeshma-portfolio`.
2. Upload `index.html`, `style.css`, the `assets` folder, and your `resume.pdf` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then click **Save**.
6. After publishing, the site will be available at:
   `https://YOUR-GITHUB-USERNAME.github.io/hareeshma-portfolio/`

## Customize
- Update content and links in `index.html`.
- Change the palette, layout and responsive styles in `style.css`.
- Replace `assets/hareeshma-profile.jpg` or `assets/webtech-logo.jpg` using the same filenames.

## Notes
- The website uses no JavaScript, build tools, backend or paid hosting.
- The resume link points to `resume.pdf`; add your own PDF before deployment.
- Contact uses email and telephone links. The Google Fonts import needs an internet connection; fallback fonts are included.
